# Entre Líneas — Práctica 2

Abre `index.html` en tu navegador. La página funciona sin internet ni instalaciones.

## Archivos
- `index.html`: estructura, navegación, imagen, servicios y formulario.
- `estilos.css`: colores, fuentes, tamaños, modelo de caja, Flexbox y diseño adaptable.
- `script.js`: alerta, modificación de texto, cambio de color y registro de demostración.
- `biblioteca.svg`: ilustración local de la biblioteca.

## Conceptos para la revisión
1. HTML define la estructura y el contenido de la página.
2. CSS define la presentación: colores, espacios, tamaños y distribución.
3. JavaScript permite responder a acciones del usuario.
4. HTML estructura, CSS presenta y JavaScript agrega comportamiento.
5. Una etiqueta semántica expresa la función de su contenido.
6. `header` contiene el encabezado.
7. `nav` agrupa los enlaces de navegación.
8. `section` agrupa contenido sobre un tema.
9. `footer` contiene el pie de página.
10. Un formulario reúne controles para capturar datos.
11. `input` es un control de entrada.
12. `text` recibe texto; `email`, correo; `number`, números; `date`, una fecha.
13. Flexbox distribuye elementos en una dimensión, con filas o columnas.
14. `display: flex` convierte un contenedor en flexible; sus hijos se organizan con ese modelo. `justify-content` distribuye sobre el eje principal, `align-items` alinea sobre el transversal y `gap` separa los elementos.
15. `margin` es el espacio exterior, fuera del borde.
16. `padding` es el espacio interior entre contenido y borde.
17. `border` es la línea que rodea el contenido y su padding. El contenido es el texto, imagen u otros elementos dentro de la caja.
18. Una función es un bloque de código que ejecuta una tarea al llamarlo.
19. `onclick` ejecuta código cuando se hace clic en un elemento.
20. `document.getElementById()` busca un elemento mediante su identificador.

## Ejemplos para mostrar al docente
- HTML: `<section id="servicios">` organiza las tarjetas.
- CSS: `.tarjetas` utiliza `display: flex`, `justify-content`, `align-items` y `gap`.
- JavaScript: `cambiarTexto()` busca `mensaje` y cambia su `textContent`.
